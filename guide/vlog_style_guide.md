## 2. 자막 시스템 (가장 중요)

자막은 역할이 다른 4가지가 정해진 위치와 색으로 반복돼요.

| 종류 | 위치 | 색 / 스타일 | 폰트 계열 (추정) | 쓰임 |
|---|---|---|---|---|
| **① 기본 자막** | 하단 중앙 (아래에서 약 8%) | 흰색 + 얇은 검정 그림자. 배경 박스 없음 | 굵은 고딕 (비슷한 폰트: Pretendard SemiBold, 지마켓 산스 Medium) | 말하는 내용, 나레이션. 거의 모든 컷에 들어감 |
| **② 노란 머리말** | 기본 자막 바로 위 | 노랑(#F5E663 근처) + 그림자. 기본 자막보다 작게 | ①과 같은 폰트 | 상황 설명, 속마음, 앞선 얘기 요약. "~한 사실", "^^^^^" 같은 톤 |
| **③ 핑크 강조 자막** | 화면 정중앙 (크게) | 핑크(#F27BB8 근처) + 얇은 흰 테두리 + 연한 그림자 | 둥근 고딕 (비슷한 폰트: 티머니 둥근바람체, 카페24 써라운드) | 리액션 펀치라인, 챕터 제목, 놀람 포인트 |
| **④ 핑크 세리프 라벨** | 화면 중앙 또는 중앙 왼쪽 | 같은 핑크, 세리프 | Garamond 계열 (비슷한 폰트: EB Garamond, Cormorant) | **시간**("4pm", "7pm"), **장소 이름**, **영어 대사 인용** |

보조로 쓰는 자막:
- **노란 큰 자막(가운데)**: ③과 같은 크기의 노랑. 혼잣말이나 속마음을 길게 강조할 때 써요.
- **엔딩 손글씨**: 귀여운 손글씨체(비슷한 폰트: 카페24 숑숑, 나눔손글씨 계열)에 진한 핑크. 마지막 한 줄에만 써요.
- **이모지**: 기본 자막 끝에 💗😊💗처럼 1~3개, 가끔만 붙여요.

### 자막 문체 규칙
- **반말 + 존댓말 섞기**: "~왔어요"와 "~함 / ~중" 같은 음슴체를 번갈아 써요.
- **말줄임표를 길게**: "....." "…"를 써서 지친 느낌이나 체념을 표현해요.
- **초성체와 기호**: ㄹㅇ, ㅋㅋㅋㅋ, ^^, ???
- **자막 = 진짜 속마음**: 화면에서 하는 말과 자막이 살짝 어긋나게 써서 웃음을 만들어요. 예: 웃으며 말하는데 자막은 "멘탈 나감".
- **한 줄 최대 약 30자**: 길면 2줄로 나누고, 2줄이 되면 ② 노란 머리말 + ① 흰 자막 구조로 바꿔요.

### 레이어 조합 예시 (화면 배치)
```
            [③ 핑크 강조 자막 — 크게, 정중앙]


   [② 노란 머리말 — 작게]
 [① 흰색 기본 자막 — 하단 중앙]               [채널 로고]
```

## 3. 화면, 촬영, 효과

- **얼굴 블러**: 얼굴은 항상 강한 가우시안 블러(모자이크 아님, 부드럽게 뭉갠 원형)로 가려요. 얼굴을 따라 움직이는 트래킹 블러예요.
- **채널 워터마크**: 오른쪽 아래에 작은 빨간 정사각 로고가 영상 내내 떠 있어요.
- **촬영 앵글**: 아이폰 셀카를 아래에서 위로(하늘이나 천장이 보이게), 손에 들고 걷는 시점, 책상 위에 세워두고 말하는 정면 컷을 써요.
- **색감**: 보정을 거의 안 한 자연광 그대로예요. 낮은 밝고 쨍하게, 밤 카페는 따뜻한 주황 조명 그대로 둬요.
- **전환**: 거의 전부 **하드컷**이에요. 페이드나 화려한 트랜지션은 없어요.
- **인서트 오버레이**:
  - 메시지(문자) 캡처를 가로로 넓게 화면 가운데에 띄워요.
  - 관련 사진을 사각형으로 가운데에 띄우고, 그 위에 ③ 핑크 자막을 올려요.
  - 화면(노트북, 휴대폰)을 접사로 찍어 결과를 보여줘요. 예: 퀴즈 점수 화면.

## 4. 컷 편집 리듬

개강 브이로그 부분(약 3분 35초) 측정값:

- 컷 수 38개, **평균 컷 길이 약 5.5초, 중간값 약 4초**
- 가장 짧은 컷 약 1.3초 (B-roll 연속), 가장 긴 컷 약 21초 (셀카 토크)
- 패턴:
  - **이동 / B-roll 구간**: 1.5~4초 컷을 빠르게 이어 붙여요.
  - **셀카 토크 구간**: 10~20초씩 길게 두되, **자막이 2~4초마다 바뀌어서** 지루하지 않게 해요.
  - 말 사이의 공백(숨, "음…")은 잘라내는 **점프컷**이에요.

## 5. 영상 흐름 (구성)

녹화된 구간 기준 타임라인이에요.

| 시간 | 장면 | 편집 포인트 |
|---|---|---|
| 0:00–0:14 | **오프닝**: 하늘 배경 셀카, 머리가 바람에 날림 | 하단에 상황 한 줄("개강 X주차… 생존 중" 톤). 0:10쯤 ③ 핑크 **타이틀**("학교 간다" 톤) |
| 0:14–0:22 | 이동 (우버 뒷자리 셀카 토크) | ① 기본 자막으로 상황 설명 |
| 0:22–0:32 | 캠퍼스 도착 B-roll (넓은 캠퍼스, 걷는 발, 문) | 빠른 컷 3~4개 |
| 0:30–0:34 | 붐비는 학생 식당/카페 | ② 노랑 + ① 흰 2단 자막으로 "알게 된 사실" 정보 전달 |
| 0:34–0:38 | 수업 들어가기 직전 노트북 | ④ 세리프 **시간 라벨**("4pm 수업") |
| 0:40–1:30 | **메인 토크**: 벽 앞 셀카, 수업과 문화 차이 썰 | 메시지 캡처 인서트 → ③ 핑크 리액션 자막 연속 (놀람 → 당황 → 체념) |
| 1:32–1:34 | **결과 공개**: 퀴즈 점수 화면 접사 | 짧은 자막 한 줄로 반전 |
| 1:40–2:00 | 수업과 공부 B-roll (필기, 휴대폰 시계, 노트북) | 잔잔하게 이어 붙임 |
| 2:02–2:10 | 친구 차로 이동, 밤 드라이브 | ③ 핑크 "정신 차려보니 ~" 전환 자막 |
| 2:12–2:22 | 카페 도착 | ④ 세리프 **장소 이름**, 이어서 **"7pm"** 시간 라벨 |
| 2:24–3:30 | **두 번째 토크**: 카페 셀카, 친구와 있었던 일 | 사진 인서트 + ③, 영어 대사는 ④ 세리프로 인용, 속마음은 노란 큰 자막 |
| 3:32–3:35 | **엔딩** | 손글씨 핑크 한 줄 마무리 + "오늘은 여기까지" 톤 기본 자막 → 바로 끝 (아웃트로 화면 없음) |

**구성 공식**
```
훅(상황 한 줄) → 핑크 타이틀 → 이동 → 장소 도착 B-roll
→ [시간 라벨] → 토크(썰) + 인서트 + 핑크 리액션 → 결과 / 반전
→ 이동 전환 자막 → [장소 라벨] → [시간 라벨] → 두 번째 토크 → 손글씨 엔딩
```
- 하루를 **시간순**으로 따라가요.
- 장면이 바뀔 때마다 **시간이나 장소 라벨**로 위치를 알려줘요.
- 각 덩어리 끝에 **작은 반전이나 펀치라인**을 하나씩 둬요.
